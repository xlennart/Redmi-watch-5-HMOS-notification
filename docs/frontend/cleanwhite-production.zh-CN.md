## 交互与状态接入

- 主要导航映射 `HOME / MUSIC / DEVICE`，初始化沿用 `SETUP / MATERIAL / EXIT_SETUP`。更换设备先确认停止通知与音乐。
- 转发开关以确认后的 `relayEnabled` 绘制；使用命令按钮表达启停。取消弹窗、失败或等待期间不会把用户点击当作服务成功。
- 权限与获准来源分开。`permissionKnown=false` 表示未知，不能显示零来源或声称已撤销。
- 快速测试沿用 `QUICK_TEST`，真实停止与释放后开始测试。传输收包与 `CONFIRM_VISIBLE / CONFIRM_NOT_VISIBLE` 人工反馈独立。
- 进阶检查确认后排入本页待办，观察真实 `pendingKind=stop` 完成；只有停止无错误、通知和音乐均关闭、`sessionBusy=false` 时才发诊断命令。停止失败不开始诊断。导航、返回、销毁会取消待办，不使用延时猜测释放。
- 暂停恢复入口只根据先前确认的暂停操作与当前真实开关显示，开启仍重新走原服务校验。页面生命周期内记录先前暂停的功能，不自动恢复。
- 导入沿用真实文件选择、取消任务、候选确认与安全保存；原有材料在取消或失败时保留。
- 音乐状态来自 `musicAvailable / musicEnabled / musicStage`；连接未知、权限不足、后台音量 `-66`、音量未变 `-67` 均保留明确文案。没有伪造曲目或播放按钮。
- 原生 `AVVolumePanel` 保留前台绑定方式与 48 vp 高度约束，位于滚动内容与底部导航之间；不自行伪造音量值。
- 图标详情使用真实 `iconResourceAccess / iconStatus / iconReason / diagnosticIconStatus / diagnosticIconReason`，不固定离线映射数量，不覆盖其他会话更新的离线图库。
