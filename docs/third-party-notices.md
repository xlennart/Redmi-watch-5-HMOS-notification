# References and dependencies

- HarmonyOS project layout, manifest fields and Hvigor task registration were assembled with reference to the official `@deveco/deveco-cli@1.3.0-stable` package and its application template. The official package declares MIT; its templates include Huawei Apache-2.0 notices where applicable. No CLI binaries, bundled documentation or third-party SDK are redistributed in this repository.
- `typescript@5.9.3` (Apache-2.0) and `json5@2.2.3` (MIT) are cloud/local verification development dependencies. Versions and integrity hashes are fixed in `package-lock.json`; upstream license files remain in their installed packages.
- Gadgetbridge revision `86389f5366e6ecf438657e6d412bfb77b83480e2` (AGPL-3.0-or-later), credited to the Gadgetbridge contributors including José Rebelo and Yoran Vulker, is a protocol research reference: https://codeberg.org/Freeyourgadget/Gadgetbridge. The independently written serial-port implementation uses researched wire framing, command/field identifiers, the standard SPP UUID and Xiaomi's handshake parameters. HMAC/HKDF use RFC 2104/5869; AES operations use the phone's crypto service. No Java sources or generated protobuf definitions are redistributed. OronBox's more complete NotifyData schema informed the required field set and single-record envelope; its sources are not included.
- The icon and page implementation in this round were created for this project. No phone/watch screenshots or personal device identifiers are included.
- AstroBox-NG Core revision `e0a5e7887390135241f75023f60b81ccf88f2fb9` and Pb revision `03a92010056dd41af114f6f46fd612104b27bd7b`, by AstralSight Studios (AGPL-3.0 with additional attribution), are protocol research references: https://github.com/AstralSightStudios/AstroBox-NG-Module-Core and https://github.com/AstralSightStudios/AstroBox-NG-Module-Pb. Notification timestamp/group facts and the system vibration command were cross-checked with TatumRobotics revision `b2f6e220cdf54be23d85e628c0e851bf76e382bb` (which credits AstroBox's AGPL modules): https://github.com/TatumRobotics/astrobox_miband_watch. BandBurg revision `a550c61fa48d7185f545614ef724f85ca01027a2` is a phone workflow reference: https://github.com/Bandbbs/bandburg. No Rust, C#, WASM or generated protobuf files from these checkouts are included. See `astrobox-research.zh-CN.md` for scope and limitations.
- Phone onboarding research references the BandBBS guides, OronBox revision `1af1924bb0061d2afb5d3708b986e0fffa85beeb` (AGPL-3.0), and AstroBox-NG-Module-Account revision `c427e2d75b7e148f76ffc2d6db37458cf69f8857`.
