## 云端复现

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run configure:notifications
npm run check
npm run configure:baseline
git diff --exit-code -- entry/src/main/module.json5 entry/src/main/ets/config/ProbeMode.ets
```

GitHub Actions 执行同一核心/模式检查。共享核心通过机械映射为 TypeScript 测试；这不替代 ArkTS 编译，也不替代 ACL 签名或真机行为。云端不要提交生成的通知模式文件，不要以 Node 测试通过宣称鸿蒙安装或手表显示通过。

本地构建与签名按照 `docs/local-build.zh-CN.md`；验证证据边界按照 `docs/phone-watch-validation.zh-CN.md`。本机 HAP、签名配置、证书私钥、用户日志、账号会话、手机截图与设备原始标识不上传。云端不需要这些材料。
